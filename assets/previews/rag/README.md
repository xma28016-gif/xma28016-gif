# RAG 中台界面实录

本目录的界面来自知境 RAG 在本机测试环境中的实际运行，录制日期为 2026 年 11 月 24 日，源码版本为 [af2fef4](https://github.com/xma28016-gif/zhijing-rag/commit/af2fef4)。

`tour.gif` 依次展示工作台、知识库、文档列表、分块、助手、运行日志、历史回答和引用执行实录。动图在真实操作截图上添加步骤标题、鼠标位置与点击提示；页面数据来自已有测试资料与历史问答记录，未重新发送模型请求。`poster.webp` 为静态封面，其余六张 WebP 为 1440 × 1000 视口截图。

画面中的 Tokens、成功率和耗时对应当时的测试记录，用于展示日志界面，不作为产品性能基准。截图与动图由个人主页的 `profile.json` 索引；运行主页生成脚本会保留这些媒体文件。
